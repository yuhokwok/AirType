# AirType 私隱政策／Privacy Policy（待確認及發布）

Draft date: 2026-10-17. This is a source-based draft for the current Web Access release. Verify the final shipping build and the operator's details before publication.

AirType 讓使用者透過本地網絡，將電腦瀏覽器輸入的文字傳到 iPhone 或 iPad 上的 AirType 鍵盤。

文字與連線：你按下傳送的文字、刪除及換行指令會經本地網絡傳送至裝置上的鍵盤。Web Access 使用 HTTP，傳輸並不加密；請使用可信任的 Wi-Fi。AirType 不會把目前文字欄位的周邊內容傳回電腦。

帳戶與儲存：AirType Web Access 不需要帳戶或自家雲端服務。瀏覽器草稿只保留於目前開啟的頁面，不使用 local storage；重新整理或關閉頁面可能遺失。已送達文字會由接收它的 App 按該 App 的規則儲存。自訂 Bonjour 名稱等偏好設定會保留在裝置。

權限：遠端輸入需要鍵盤的「完整取用」及本地網絡權限。本機打字不需要完整取用。連線只在 Web Access 鍵盤顯示時運作。

分析與追蹤：按目前原始碼檢視，未見加入廣告或第三方分析 SDK。營運者應在發布前核對最終發佈版本及依賴。

AirType lets you send text from a computer browser to the AirType keyboard on your iPhone or iPad over a local network.

Text and connections: Text you send, delete commands, and newline commands travel over the local network to your device. Web Access uses unencrypted HTTP; use a trusted Wi-Fi network. AirType does not return the surrounding contents of the destination text field to the computer.

Accounts and storage: Web Access does not require an account or an AirType cloud service. Browser drafts stay in the current page without local storage and may be lost when you refresh or close it. The receiving app handles any storage of delivered text under its own policies. Preferences such as a custom Bonjour name are stored on the device.

Permissions: Remote typing requires keyboard Full Access and Local Network permission. Local typing works without Full Access. The receiving connection operates only while Web Access is visible.

Analytics and tracking: No advertising or third-party analytics SDK was identified in the current source review. The operator should verify the final shipping binary and its dependencies before publishing this policy.

電腦上打字，iPhone、iPad 上接收。

回覆長訊息、整理筆記，或輸入一大段文字時，繼續使用你熟悉的電腦鍵盤。AirType 透過同一 Wi-Fi，將電腦瀏覽器內輸入的文字，傳到 iPhone 或 iPad 目前的文字欄位。

打開瀏覽器，就能開始
電腦毋須安裝額外軟件，也毋須建立帳戶。在電腦瀏覽器開啟 AirType 鍵盤顯示的網址，再輸入六位數配對碼，即可連接。

用你熟悉的輸入方式
在電腦上使用中文或其他語言輸入法，完成文字後按 Enter 或傳送按鈕。瀏覽器亦提供刪除及換行控制，並內置可搜尋的 Emoji 選單，方便把表情符號加入草稿。

手機上也能直接打字
隨時切換至本機英文 QWERTY 鍵盤，支援淺色及深色外觀、數字、符號與英文拼字建議。長按空白鍵並左右拖動，可移動游標。

連線中斷，保留未送草稿
瀏覽器遇到斷線時會嘗試重新連接，最多持續 10 秒；之後可按 Reconnect 手動再試。未送出的草稿會保留在目前開啟的網頁，方便你繼續編輯。

開始使用
1. 在系統設定加入 AirType 鍵盤，並允許「完整取用」。
2. 在 AirType App 啟用本地網絡連線，允許本地網絡存取。
3. 將電腦與 iPhone 或 iPad 連接至同一 Wi-Fi。
4. 在支援的 App 開啟文字欄位，切換至 AirType 並保持 Web Access 畫面顯示。
5. 在電腦開啟鍵盤所示網址，輸入配對碼，開始打字。

使用須知
• 需要 iOS／iPadOS 17 或以上版本。
• 遠端輸入需要「完整取用」及本地網絡權限。本機打字毋須完整取用。
• 連線只在 Web Access 鍵盤畫面顯示時運作。
• 部分 App 不支援第三方鍵盤；密碼及部分電話號碼欄位會使用系統鍵盤。
• AirType Web Access 使用本地 HTTP 連線，傳輸不加密。請使用可信任的 Wi-Fi。
• 無須雲端帳戶；AirType 不會將輸入文字上傳至自家雲端服務。網頁草稿只保留於當前頁面，重新整理或關閉頁面可能遺失草稿。
